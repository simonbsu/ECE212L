## Lab Questions

### In plain English describe the function and use of a multiplexer.
The multiplexer lets you output one input from a bank of inputs, selecting which one with selector bit(s).

### In plain English describe the function and use of a demultiplexer.
The demultiplexer lets you take an input and foward it to one of many outputs, selecting which one with selector bit(s).

### What other uses might these circuits have? (Think Shannon’s)
Using Shannon's expansion, you can actually wire logic functions with multiplexers. Not only can these circuits route signals, but it can be used to perform operations.
